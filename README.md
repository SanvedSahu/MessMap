# MessMap

## Project Overview
MessMap is a full-stack application that helps users discover mess facilities using location-based services.

## Technology Stack
- Frontend: React with TypeScript
- Backend: Java Spring Boot
- Database: MySQL
- Maps: To be finalized

## Project Modules
- User
- Admin
- Mess Owner

## Repository Structure
- `docs/` — Project documentation
- `frontend/` — Frontend application
- `backend/` — Backend application
- `database/` — Database scripts
- `testing/` — Test plans and cases

## Development Branch
`development` is the default integration branch.
